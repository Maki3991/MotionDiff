- 当前状态：`feature/ai-feedback` 已实现单次侧面深蹲的 MediaPipe 证据提取、后端 AI 建议和网页展示；真实 API 已返回建议，但服务商延迟会导致偶发超时，建议是否对动作有用仍待本人按视频人工核对。

## 已经做到

- 2026-10-03：完成 `action=squat` 的证据提取、AI 请求、严格结构校验、失败降级和网页 AI 建议区；原有完整报告、视频播放、证据跳转和 Markdown 保留。

- 两段视频经 MediaPipe 全帧处理，生成逐帧 JSON、对齐结果、相对差异及可回看的双视频证据时间点。
- 固定 `test2` 视频已实际运行；同一对素材的 7 次应用运行耗时为 15.55～19.11 秒。此结果不代表长视频也能在一分钟内完成。
- 当前只在姿态数据不足时返回“无法判断”；没有可靠的机位偏差自动判定，也没有自动识别动作语义。
- 深蹲分段是本地启发式质量门槛，不是动作识别模型；当首尾站立角度、单次活动区间或最低位两侧证据不满足时会返回无法判断，即使人眼认为动作完整。该门槛需要用更多标注视频校准。

## 本轮优先：让报告可供人核对

- [ ] 由团队成员逐条回看 AI 建议给出的参考／学员对应片段，记录“部位、时间、差异描述、调整动作”哪些说对、哪些说错或无法确认。
- [ ] 依据核对结果改进差异排序、证据呈现与相对参考动作的措辞；明确区分“检测到的差异”和“尝试靠近参考的提示”，不把相似度指数当合格线。
- [ ] 使用 `test1`、`test2` 之外的新录同类动作验证：正常重复不应出现大量无依据提示，刻意变化应能定位到正确侧别和片段。完成情况以人工核对记录为准。

以上是下一阶段计划，不表示报告改进和新录验收已经完成。
