## 已经做到

- 两段视频经 MediaPipe 全帧处理，生成逐帧 JSON、对齐结果、相对差异及可回看的双视频证据时间点。

- 当前只在姿态数据不足时返回“无法判断”；没有可靠的机位偏差自动判定，也没有自动识别动作语义。

## 本轮优先：让报告可供人核对

- [ ] 由团队成员逐条回看报告给出的参考／学员对应片段，记录“部位、侧别、时间、差异描述”哪些说对、哪些说错或无法确认。
- [ ] 依据核对结果改进差异排序、证据呈现与相对参考动作的措辞；明确区分“检测到的差异”和“尝试靠近参考的提示”，不把相似度指数当合格线。
- [ ] 使用 `test1`、`test2` 之外的新录同类动作验证：正常重复不应出现大量无依据提示，刻意变化应能定位到正确侧别和片段。完成情况以人工核对记录为准。

以上是下一阶段计划，不表示报告改进和新录验收已经完成。
